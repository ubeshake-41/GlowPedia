Design in Three Words: "Structured Soft Clarity"

800-weight typography

Sora at maximum weight anchors every section. Bold type signals confidence — the single biggest fix from the Base44 draft.

Hard left border accents

4px coloured left borders on cards replace top gradient bars. Vertical structure reads as directional and bold, not decorative.

Section rules + ALL-CAPS labels

Full-width horizontal rules with uppercase labels give every section a clear header. Magazine/editorial structure — works for all genders.

Rectangular tags, not pills

Good For / Avoid If uses a two-column table layout with sharp-corner tags. Data feels precise and scannable, not bubbly.

Solid VS badge

Dark rectangular VS pill instead of a soft yellow one. Small but signals decisiveness — the compare feature is a tool, not decoration.

Progress bar = flat rectangle

No border-radius on progress fills. Data viz elements stay geometric — structure within soft surroundings.

2px borders throughout

Heavier borders than Base44's 1px. Structural lines need to be visible — invisible borders make layouts feel like they're floating.

Orbs: atmosphere only

Large but very low opacity (0.08–0.22). They add depth without becoming decorative focal points that read as overtly feminine.
